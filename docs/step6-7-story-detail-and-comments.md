# ステップ6・7 振り返り：ストーリー詳細ページ & コメント機能

このドキュメントは「文倉」開発ステップ6（ストーリー詳細ページ）とステップ7（コメント機能）の振り返りです。
基礎説明は最小限にし、**「なぜそう作るか」**と**コードを読んで言語化する練習**、そして**理解度チェック問題（解答つき）**を中心にまとめます。

---

## 0. この2ステップで作ったものを一言で

> - **ステップ6**：ストーリー1編を全文で読める**詳細ページ**を作った（完成は全員、下書きはログイン必須）。
> - **ステップ7**：その詳細ページで**コメントの投稿・表示・削除**ができるようにした（ログイン時のみ）。

これで「お題 → ストーリー一覧 → 1編を読む → 感想をコメントする」という一連の体験がつながりました。

## 1. 全体の流れ

### ステップ6：詳細ページを開くまで

```
お題詳細ページのストーリーカードをクリック
        │  wire:navigate（高速遷移）
        ▼
/stories/{story} …… ルートモデルバインディングでStoryを自動取得
        │  mount()
        ▼
[門番] 下書き かつ 未ログイン なら 403 で拒否
        │
        ▼
本文・作者・状態バッジ・いいね/コメント数を表示
```

### ステップ7：コメントの投稿

```
詳細ページのコメント欄（ログイン時のみ表示）
        │  wire:submit="addComment"
        ▼
1. バリデーション（必須・文字列・最大2000文字）
2. このストーリーに紐づくコメントを作成（story_id 自動、user_id は自分）
        │
        ▼
入力欄リセット + トースト通知 + 一覧が即最新化
```

## 3. なぜそう作ったのか（設計の意図）

### 3.1 ルートモデルバインディング

```php
// routes/web.php
Route::livewire('/stories/{story}', 'pages::stories.show')->name('stories.show');

// mount()
public function mount(Story $story): void { ... }
```

URLの `{story}` と引数名 `Story $story` が一致すると、LaravelがIDから**自動でモデルを取得**。見つからなければ**自動で404**になります（存在しないIDのテストが通る土台）。

### 3.2 下書きの公開制御は「門番」で一撃

```php
abort_if($story->status === StoryStatus::Draft && ! auth()->check(), 403);
```

「下書き **かつ** 未ログイン」なら403で止める。完成ストーリーは全員OK、という要件を1行で表現しています。

### 3.3 コメントもリレーション経由で作る（ステップ5と同じ型）

```php
$this->story->comments()->create([
    'body' => $validated['body'],
    'user_id' => auth()->id(),
]);
```

`親->子ら()->create([...])` は「**この親にぶら下がる子を1件作る（親のIDは自動セット）**」という超頻出パターン。`story_id` を自分で書かなくても入ります。

### 3.4 削除は「本人だけ」を保証

```php
$comment = $this->story->comments()->findOrFail($commentId);
abort_unless($comment->user_id === auth()->id(), 403);
$comment->delete();
```

- `findOrFail` で、そのストーリー配下に該当コメントが無ければ404
- `abort_unless(本人か?, 403)` で他人のコメント削除を拒否（要件「自分のコメントは削除可能」）

### 3.5 一覧は `with()` で返して常に最新

投稿・削除のたびにLivewireが再描画し、`with()` が再実行されてコメントを取り直すので、**画面が自動で最新**になります。

## 4. コード読解トレーニング（コードを見て言語化する）

各コードの下の「読み上げ方」を見る前に、まず自分の言葉で説明してみましょう。

### 問1

```php
$this->story = $story->load(['user', 'image'])->loadCount('likes');
```

**読み上げ方**：「取得済みのストーリーに、作者（user）とお題画像（image）を後から読み込み、いいねの件数を数えて `likes_count` として持たせる」

### 問2

```php
abort_if($story->status === StoryStatus::Draft && ! auth()->check(), 403);
```

**読み上げ方**：「このストーリーが下書きで、かつログインしていないなら、403で処理を止める」

### 問3

```blade
<div class="leading-relaxed whitespace-pre-line">{{ $story->body }}</div>
```

**読み上げ方**：「本文を表示する。`whitespace-pre-line` で入力時の改行を表示にも反映し、`{{ }}` なのでHTMLは無効化されて安全」

### 問4

```php
$this->story->comments()->create([
    'body' => $validated['body'],
    'user_id' => auth()->id(),
]);
```

**読み上げ方**：「今開いているストーリーに紐づくコメントを1件作る。本文は検証済みの値、投稿者は今のログインユーザー。`story_id` はリレーション経由なので自動で入る」

### 問5

```blade
@auth
    {{-- コメントフォームと一覧 --}}
@else
    {{-- ログイン誘導 --}}
@endauth
```

**読み上げ方**：「ログイン中の人にはフォームと一覧を、未ログインの人にはログイン誘導を表示する（ゲストにはコメントを見せない）」

### 言語化のコツ（再掲）

1. 左から右へ、主語・述語に変換
2. カッコの中身は「何を・どこに」
3. 記号は役割で覚える（`->`=〜の、`::`=そのクラスの機能、`&&`=かつ、`!`=否定）
