# いいねボタン（ハート表示）をやさしく振り返る

文倉（fumikura）のストーリー詳細・お題ページで、**いいねをハートマークと件数で分かりやすくした**ときの振り返りです。  
中学生やプログラミング初心者でも読めるように書いています。

あわせて、画面上の「保存」ボタンを「お気に入りに追加」に変えた話も少し触れます。

---

## 1. 何ができるようになったか

| 状態 | 画面の見え方 |
| --- | --- |
| まだいいねしていない | `♡` ＋ 件数（文字と同じ色） |
| いいね済み | `♥` ＋ 件数 |
| 件数の意味 | **自分だけでなく、他の人のいいねも含めた合計** |

クリックするたびに、いいねのオン／オフが切り替わり、件数も増減します。  
ログインしていない人は件数を見られますが、ボタンは押せません。

---

## 2. 結論：やっていることはとてもシンプル

やっていることは、ざっくり3つだけです。

```text
1. いま「いいね済みか？」を調べる（$isLiked）
2. 全員のいいね数を数える（$likesCount）
3. 画面では、済みなら ♥、まだなら ♡ を出す
```

たとえ話にするとこうです。

| 役割 | たとえ | このプロジェクトでの場所 |
| --- | --- | --- |
| スイッチ | 「押した／押してない」の状態 | `$isLiked` |
| カウンター | 何人がいいねしたかの合計 | `$likesCount` |
| 見た目 | 白抜きハートか塗りつぶしハートか | `{{ $isLiked ? '♥' : '♡' }}` |
| 押したときの処理 | DB にいいねを足す／消す | `toggleLike()` |

---

## 3. なぜハートにしたのか

以前のストーリー詳細では、いいねボタンに **数字だけ** が出ていました。

```text
[ 0 ]   0 コメント
```

これだと「0 が何の数字か」が分かりにくいです。  
お題ページの一覧にはすでに `♥` があったので、詳細ページも合わせて、

```text
[ ♡ 0 ]   0 コメント
```

のようにしました。

件数はもともと「全員のいいね合計」でした。  
ハートをつけることで、「これはいいねの数だ」と一目で分かるようになります。

---

## 4. 実際のコードで見る

ここではストーリー詳細（`resources/views/pages/stories/⚡show.blade.php`）を例にします。

### 4-1. 画面のボタン

```blade
<button
    type="button"
    wire:click="toggleLike"
    aria-label="いいね"
    @class([
        'btn btn-sm gap-1',
        'btn-primary' => $isLiked,
        'btn-ghost' => ! $isLiked,
    ])
>
    <span aria-hidden="true">{{ $isLiked ? '♥' : '♡' }}</span>
    <span>{{ $likesCount }}</span>
</button>
```

| 部分 | 意味 |
| --- | --- |
| `wire:click="toggleLike"` | 押したら PHP 側の `toggleLike` を動かす |
| `btn-primary` / `btn-ghost` | いいね済みかどうかでボタンの色を変える |
| `{{ $isLiked ? '♥' : '♡' }}` | ハートの形を切り替える |
| `{{ $likesCount }}` | いいねの合計件数を出す |

### 4-2. いちばん大事な1行

```blade
{{ $isLiked ? '♥' : '♡' }}
```

部品ごとに見るとこうです。

| 部品 | 意味 |
| --- | --- |
| `{{ ... }}` | 結果を画面に出す（Blade の書き方） |
| `$isLiked` | いいね済みなら `true`、まだなら `false` |
| `?` と `:` | 「もし〜なら A、そうでなければ B」 |

表にすると:

| `$isLiked` | 選ばれる文字 | 画面 |
| --- | --- | --- |
| `true`（済み） | `'♥'` | ♥ |
| `false`（未） | `'♡'` | ♡ |

### 4-3. if で書くと同じ

長く書くとこうなります。

```blade
@if ($isLiked)
    ♥
@else
    ♡
@endif
```

`? :` は、これを短くしただけです。中身は同じです。

---

## 5. `? :` と `if`、どちらを使う？

流行りというより、**場面に合った書き方を選ぶ**のが普通です。

| 書き方 | 向いているとき |
| --- | --- |
| `? :`（三項演算子） | 「A か B か」の短い選択（ハート1文字など） |
| `@if` / `if` | 条件が複雑、やる事が複数、あとから読み返したい |

今回は「♥ か ♡ か」だけなので、1行の `? :` の方が見通しがよい、という判断です。

何でも `? :` にすると読みにくくなります。入れ子が深いときは `if` の方が親切です。

## 6. 件数はどうやって決まっているか

画面に渡すデータは、だいたい次のようなイメージです。

```php
'likesCount' => $this->story->likes()->count(),
'isLiked' => auth()->check()
    && $this->story->likes()->where('user_id', auth()->id())->exists(),
```

| 変数 | 調べていること |
| --- | --- |
| `$likesCount` | このストーリーへのいいね件数（全員） |
| `$isLiked` | **今ログインしている人**がいいね済みか |

だから、他の人が先にいいねしていると、自分はまだ押していなくても `♡ 1` のように見えます。  
自分が押すと `♥ 2` になります。

---

## 7. 押したときに裏で起きること

`toggleLike()` は、ざっくり次の動きです。

```text
すでに自分のいいねがある？
  → ある：消す（いいね解除）
  → ない：作る（いいね追加）
```

データベースの `likes` テーブルに、

- どのストーリーか（`story_id`）
- 誰が押したか（`user_id`）

を記録します。同じ人が二重にいいねしないように、トグル（入り切り）になっています。

---

## 8. 未ログインの人にはどう見える？

ログインしていない人には、ボタンではなく表示だけにしています。

```blade
<span ...>
    <span aria-hidden="true">♡</span>
    <span>{{ $likesCount }}</span>
</span>
```

- 件数は見られる  
- クリックしていいねはできない（ログインが必要）

---

## 9. お気に入りボタンとの違い（ついでに）

同じ行に、「お気に入り」ボタンもあります。

| 機能 | 見た目の例 | 役割 |
| --- | --- | --- |
| いいね | `♡ 3` / `♥ 3` | みんなに見える応援の数 |
| お気に入り | 「お気に入りに追加」／「お気に入り済み」 | 自分用のしおり（あとで読み返す） |

今回の振り返りのメインはいいねですが、文言は「保存」から「お気に入りに追加」へ揃えています。

## 11. 学習のヒント：出てきたことば

| ことば | やさしい意味 |
| --- | --- |
| Blade | Laravel の画面テンプレート |
| `{{ }}` | 計算結果や変数を画面に出す |
| 三項演算子（`? :`） | 「もし〜なら A、아니면 B」を1行で書く書き方 |
| Livewire（`wire:click`） | ボタンを押すとサーバ側の処理を動かす仕組み |
| トグル | オン／オフを切り替え続ける操作 |
| `aria-label` | 音声読み上げなど向けの、ボタンの名前 |

## 12. よくある質問

### Q. 件数は自分のいいねだけ？

A. いいえ。**他の人も含めた合計**です。`$likesCount` が全員分を数えています。

### Q. なぜ白抜きと塗りつぶしを分けるの？

A. 「まだ押していない／もう押した」が一目で分かるようにするためです。  
未いいねは他の文字と同じ色の `♡`、済みは `♥` にしています。

### Q. if で書かないのは流行り？

A. 流行りというより、**短い切り替えに向いているから**です。  
複雑になったら `if` の方が読みやすいです。
