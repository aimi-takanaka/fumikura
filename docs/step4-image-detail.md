## 0. このステップで作ったものを一言で

> トップページのカードを押すと、その**お題の詳細ページ（画像＋ストーリー一覧）**に移動できるようにした。

これで「一覧 → 詳細」という、Webサイトの基本的な画面のつながりができました。

## 1. 全体の流れ

```
トップページのカードをクリック
        │  <a href="/images/{id}" wire:navigate>
        ▼
routes/web.php  …… /images/{image} は pages::images.show を表示
        │
        ▼
[ルートモデルバインディング] URLのidから自動でImageを取得（無ければ404）
        │
        ▼
pages/images/⚡show.blade.php
   ・画像＋タイトル＋投稿者
   ・そのお題のストーリー一覧
        │  閲覧制限：ゲストは完成のみ／ログイン中は下書きも
        ▼
画面に表示
```

## 3. なぜそう作ったのか（設計の意図）

### 3.1 ルートモデルバインディング（自分でDB検索を書かない）

ルートを `/images/{image}`、メソッドを `mount(Image $image)` にするだけで、
Laravel が **URLの id から該当の Image を自動で探して渡してくれます**。

- 自分で「id で検索して、無ければ404」を書く必要がない
- 存在しないidなら自動で404になる（安全）

### 3.2 閲覧制限は「1か所」で効かせる

要件では、下書き（散文・アイデア）はログインユーザーだけが読めます。
これをデータ取得の時点で絞り込むことで、**表示側であれこれ分岐しなくて済みます**。

```php
->unless(auth()->check(), fn ($query) => $query->complete())
```

「ログインしていない時だけ、完成に絞る」——これ1行でゲストと会員の出し分けが完成します。
（`when` の逆が `unless`。“〜でない時だけ”）

### 3.3 件数は withCount で軽く取る

いいね・コメントは「本文」ではなく「件数」だけ表示したいので、`withCount` を使います。
本文まで読み込まないので速く、`$story->likes_count` のように使えます。

## 4. コード読解トレーニング（コードを見て言語化する）

各コードの下に「読み上げ方（模範解答）」があります。まず自分の言葉で説明してみてから答え合わせしましょう。

### 問1

```php
public function mount(Image $image): void
{
    $this->image = $image->load('user');
}
```

**読み上げ方**：「URLで指定されたお題（Image）を受け取り、その投稿者（user）も一緒に読み込んで、コンポーネントに保持する」

- `mount(Image $image)` = 「ルートから渡ってきた Image を受け取る」
- `->load('user')` = 「あとで投稿者名を出すため、user を先に読み込む（N+1防止）」

### 問2

```php
$this->image->stories()
    ->with('user')
    ->withCount(['likes', 'comments'])
    ->unless(auth()->check(), fn ($query) => $query->complete())
    ->latest()
    ->get();
```

**読み上げ方**：「このお題に紐づくストーリーを、作者付き・いいね/コメント件数付きで、（未ログインなら完成だけに絞って）新しい順に取得する」

- `stories()` = 「このお題のストーリーたち」
- `with('user')` = 「各ストーリーの作者もまとめて取得」
- `withCount([...])` = 「いいね・コメントの件数を数える」
- `unless(auth()->check(), ...)` = 「未ログインの時だけ完成に絞る」
- `latest()->get()` = 「新しい順で取得」

### 問3

```blade
@guest
    <flux:text>※ ログインすると、下書き（散文・アイデア）も読めるようになります。</flux:text>
@endguest
```

**読み上げ方**：「未ログインの人にだけ、この案内文を表示する」

- `@guest ... @endguest` = 「ログインしていない人限定の表示ブロック」

### 問4

```blade
@if ($story->status === StoryStatus::Complete)
    <flux:badge color="lime">完成</flux:badge>
@else
    <flux:badge color="zinc">散文・アイデア</flux:badge>
@endif
```

**読み上げ方**：「ストーリーが完成なら緑の『完成』バッジ、そうでなければグレーの『散文・アイデア』バッジを出す」

- `$story->status === StoryStatus::Complete` = 「状態が“完成”かどうか」
- Enum を使っているので、文字列の打ち間違いが起きない

### 問5

```blade
<a href="{{ route('images.show', $image) }}" wire:navigate class="block ...">
    <flux:card>...</flux:card>
</a>
```

**読み上げ方**：「カード全体を、その画像の詳細ページへのリンクにする。クリックするとスムーズに移動する」

- `route('images.show', $image)` = 「その画像の詳細ページのURLを作る」
- `wire:navigate` = 「ページ全体を再読み込みせず、素早く画面を切り替える」

### 言語化のコツ（再掲）

1. 左から右へ、主語・述語に変換
2. カッコの中身は「何を・どこに」
3. 戻り値は「〜を受け取る」
4. 記号は役割で覚える（`?->`=安全に読む、`=>`=ペア、`::`=そのクラスの機能、`===`=同じか比べる）
