# 文倉 要件定義書

2025年6月

---

## 1. プロジェクト概要

### 1.1 サービス概要

「文倉」は、管理者が投稿した画像（お題）に対して、ユーザーが自由にストーリーを綴ることができる創作掲示板アプリケーションです。

同じ一枚の画像から複数のストーリーが生まれる体験を通じて、創作活動を楽しむユーザーが集まるコミュニティを目指します。

### 1.2 開発目的

- 創作活動（ストーリー執筆）を楽しむ人々の交流の場を提供する
- 管理者によるお題画像の管理で安全なコンテンツ環境を維持する
- ポートフォリオとして Laravel / Livewire の技術スタックを実践的に示す

### 1.3 技術スタック

| 項目 | 内容 |
| --- | --- |
| バックエンド | PHP / Laravel |
| フロントエンド | Livewire / Blade |
| データベース | MySQL |
| 認証 | Laravel Breeze（予定） |
| バージョン管理 | Git / GitHub |

## 2. ユーザー定義

| ユーザー種別 | 説明 | 主な権限 |
| --- | --- | --- |
| ゲスト（未ログイン） | アカウントを持たない閲覧者 | 完成ストーリーの閲覧のみ |
| 一般ユーザー（ログイン済み） | アカウント登録済みのユーザー | 投稿・コメント・いいね・お気に入り |
| 管理者 | サービス運営者 | 画像（お題）のアップロード・管理、全コンテンツの管理 |

## 3. 機能要件

### 3.1 認証機能

- ユーザー登録（メールアドレス・パスワード）
- ログイン / ログアウト
- メール認証（任意：実装できれば追加）

### 3.2 閲覧制限

| コンテンツ | ゲスト | ログイン済みユーザー |
| --- | --- | --- |
| 完成ストーリー | ○ 閲覧可 | ○ 閲覧可 |
| 散文・アイデア（下書き） | ✕ 閲覧不可 | ○ 閲覧可 |
| コメント | ✕ 閲覧不可 / 投稿不可 | ○ 閲覧可・投稿可 |
| いいね・お気に入り | ✕ 使用不可 | ○ 使用可 |

### 3.3 画像（お題）管理機能

- 管理者のみ画像をアップロード可能
- 画像一覧の表示（トップページ / 一覧ページ）
- 画像に紐づくストーリーの一覧表示

### 3.4 ストーリー投稿機能

- ログインユーザーのみ投稿可能
- タイトル・本文の入力
- 投稿時にステータスを選択可能

| ステータス | 説明 | 閲覧制限 |
| --- | --- | --- |
| 完成 | 完成したストーリー | 誰でも閲覧可 |
| 散文・アイデア | 書きかけ・アイデアメモ | ログイン済みユーザーのみ閲覧可 |

※ ステータスは投稿後も変更可能とする

### 3.5 コメント機能

- ログインユーザーのみコメント投稿可能
- ストーリー詳細ページにコメントを表示
- 自分のコメントは削除可能

### 3.6 いいね機能

- ログインユーザーのみ使用可能
- ストーリーに対していいねをつける・取り消す（トグル）
- いいね数の表示

### 3.7 お気に入り機能

- ログインユーザーのみ使用可能
- ストーリーをお気に入り登録・解除（トグル）
- マイページでお気に入り一覧を確認可能

### 3.8 マイページ

- 自分の投稿ストーリー一覧
- お気に入りしたストーリー一覧
- プロフィール情報の表示（ユーザー名など）

## 4. データベース設計

### 4.1 テーブル一覧

| テーブル名 | 概要 |
| --- | --- |
| users | ユーザー情報 |
| images | 管理者が投稿したお題画像 |
| stories | ユーザーが投稿したストーリー |
| comments | ストーリーへのコメント |
| likes | ストーリーへのいいね（中間テーブル） |
| bookmarks | ストーリーへのお気に入り（中間テーブル） |

### 4.2 各テーブルの主なカラム

#### users テーブル

| カラム名 | 型 | 説明 |
| --- | --- | --- |
| id | bigint (PK) | 主キー |
| name | varchar | ユーザー名 |
| email | varchar | メールアドレス（unique） |
| password | varchar | パスワード（ハッシュ） |
| is_admin | boolean | 管理者フラグ（default: false） |
| created_at / updated_at | timestamp | タイムスタンプ |

#### images テーブル

| カラム名 | 型 | 説明 |
| --- | --- | --- |
| id | bigint (PK) | 主キー |
| title | varchar | お題タイトル |
| file_path | varchar | 画像ファイルのパス |
| user_id | bigint (FK) | 投稿した管理者のID |
| created_at / updated_at | timestamp | タイムスタンプ |

#### stories テーブル

| カラム名 | 型 | 説明 |
| --- | --- | --- |
| id | bigint (PK) | 主キー |
| image_id | bigint (FK) | 紐づくお題画像のID |
| user_id | bigint (FK) | 投稿したユーザーのID |
| title | varchar | ストーリータイトル |
| body | text | ストーリー本文 |
| status | enum('complete','draft') | complete：完成 / draft：散文・アイデア |
| created_at / updated_at | timestamp | タイムスタンプ |

#### comments テーブル

| カラム名 | 型 | 説明 |
| --- | --- | --- |
| id | bigint (PK) | 主キー |
| story_id | bigint (FK) | 紐づくストーリーのID |
| user_id | bigint (FK) | 投稿したユーザーのID |
| body | text | コメント本文 |
| created_at / updated_at | timestamp | タイムスタンプ |

#### likes / bookmarks テーブル（共通構造）

| カラム名 | 型 | 説明 |
| --- | --- | --- |
| id | bigint (PK) | 主キー |
| story_id | bigint (FK) | 対象ストーリーのID |
| user_id | bigint (FK) | 操作したユーザーのID |
| created_at | timestamp | 作成日時 |

## 5. 画面一覧

| 画面名 | URL（予定） | アクセス権限 |
| --- | --- | --- |
| トップ / 画像一覧 | `/` | 全員 |
| 画像詳細・ストーリー一覧 | `/images/{id}` | 全員（散文はログイン必須） |
| ストーリー詳細 | `/stories/{id}` | 全員（散文はログイン必須） |
| ストーリー投稿 | `/stories/create` | ログイン必須 |
| ストーリー編集 | `/stories/{id}/edit` | ログイン必須（本人のみ） |
| マイページ | `/mypage` | ログイン必須 |
| 管理者：画像アップロード | `/admin/images/create` | 管理者のみ |
| ログイン / 新規登録 | `/login`, `/register` | ゲストのみ |

## 6. 非機能要件

| 項目 | 内容 |
| --- | --- |
| セキュリティ | CSRF対策（Laravel標準）、パスワードのハッシュ化、不正アクセス防止（認可チェック） |
| バリデーション | 各フォームの入力値バリデーションを実装 |
| レスポンシブ対応 | スマートフォン・タブレットでの閲覧に対応（任意） |
| コードの品質 | 適切なコメント記述、MVC設計の遵守 |
