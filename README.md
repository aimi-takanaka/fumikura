# 文倉（fumikura）

小説やシナリオを作ったことがない人でも、気軽に参加できる創作アプリです。  
お題画像をもとに物語をイメージして投稿できます。完成していなくても、人に見てもらえる「アイデア」で参加したり、自分だけが見られる「下書き」で管理したりできます。

## 技術スタック

- PHP / Laravel
- Livewire
- Laravel Fortify（認証・メール認証）
- Tailwind CSS / DaisyUI
- Vite
- Pest（テスト）
- Google Gemini API
- MySQL（本番）
- GitHub Actions（デプロイ）

## 主な機能

- お題画像をもとにしたストーリー投稿
- ステータス管理（アイデア / 下書き / 完成）と閲覧範囲の制御
- いいね・お気に入り・コメント
- マスコット「ふみ」による投稿後の応援コメント（Gemini API）
- 誤字脱字チェック（Gemini API）
- ほかの視点からのストーリー提案（Gemini API）
- メール認証付きのユーザー登録

## きっかけ・工夫した点

きっかけはシナリオ教室での周囲の声です。完成を目指すとハードルが上がるので、創作の練習場にしたいと作成しました。Gemini API でマスコット「ふみ」の応援コメントを出し、次も書きたくなる体験を工夫しました。ステータスで閲覧範囲を分け、誤字脱字チェックやメール認証も実装しています。

## ローカル起動

```bash
composer setup
composer run dev
```

ブラウザで表示された URL（例: `http://localhost:8000`）を開いてください。  
Gemini 機能を使う場合は、`.env` に `GEMINI_API_KEY` を設定します。
